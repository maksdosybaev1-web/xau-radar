# Этап: уведомление об отмене FVG-сценария

Добавлено событие Telegram `fvg_cancelled` для новых своевременно полученных отмен FVG. Сообщение содержит инструмент, направление сценария, время UTC, ID и границы старшей зоны, точную причину из журнала. Оно обозначает прекращение наблюдения за сценарием, а не закрытие позиции у брокера.

Теперь маршрут FVG поддерживает три события: приближение, подтверждение и отмену. Причины определяет существующий движок: например, истечение срока, выход за границу зоны, изменение старшей структуры или разрыв котировок. Торговые условия не изменялись.

Отмена использует отдельный ключ ограничения повторов, поэтому предыдущее уведомление о приближении её не подавляет. Работают постоянный ID, восстановление очереди из журнала и прежние ограничения свежести. Старые записи журнала не отправляются задним числом. При выключенной доставке новое событие остаётся локальным.

Проверка: **148 тестов прошли**. Новые тесты проверяют последовательность «приближение → отмена», причину сообщения, отсутствие повторной доставки после перезапуска, устаревшие данные, выключенную доставку и восстановление после сбоя SQLite. Отправка проверялась подставным обработчиком во временной базе, без обращения к Telegram.

Сервер и мост оставлены остановленными; Telegram выключен. Изменение вступит в работу при следующем разрешённом пользователем запуске и включении доставки. Проверка реального нового рыночного события пока не выполнена.
