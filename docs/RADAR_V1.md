## Что готово

- Новый основной экран «Обзор рынка», переключение M5 / M15 / H1, сравнение трёх периодов, свечной график с EMA и уровнями.
- Последняя bid/ask-котировка MT5 и спред обновляются с опросом раз в 10 секунд. Время котировки и устаревшее состояние видны явно.
- EMA20/50/200, RSI14, MACD12/26/9, ATR14, относительная активность и режим волатильности.
- Поддержка/сопротивление, направление, разбивка оценки 0–100 и WATCH при выполнении условий.
- Справочный расчёт SL/TP и условного объёма в унциях по введённому риску. Торговые заявки не создаются.
- События пересечения EMA, выхода RSI за 30/70, закрытия за уровнем, повышенного объёма/волатильности, приближения к уровню и перехода в WATCH.
- Приближение живой bid к уровню проверяется между закрытиями свечей. Остальные индикаторные события используют закрытые свечи.
- Локальная лента, уведомления браузера и подключаемый Telegram. История и стартовый разогрев не отправляются в Telegram.
- Новый обзор отделён от сценария nested-FVG из учебных материалов. Старые зоны, ручной прогон, журнал, риск открытых позиций MT5 и ИИ-пояснения остаются во вкладках.

## Точные определения

Все определения ниже — правила программы, а не дополнительные правила автора видео.

- EMA: начальное значение — SMA периода, затем коэффициент `2/(n+1)`. Для EMA200 нужно минимум 200 закрытых свечей. MT5 загружает по 600 свечей каждого периода отдельно.
- RSI14: средние роста и падения Wilder, коэффициент `1/14`; неизменная цена даёт 50, рост без падений — 100, падение без роста — 0.
- MACD: EMA12 − EMA26; сигнальная EMA9; гистограмма — разность MACD и сигнальной линии.
- ATR14: true range со сглаживанием Wilder. Это измерение прошлых диапазонов, а не прогноз будущего движения.
- Активность: объём текущей закрытой свечи / среднее 20 предыдущих. В MT5 используется тиковая активность брокера, не совокупный биржевой объём золота. Значения разных поставщиков непосредственно не сравниваются.
- Волатильность: ATR / медиана 100 предыдущих ATR. От 1,5 — высокая; ниже 0,75 — низкая; иначе обычная.
- Уровни: строгий локальный экстремум с двумя свечами слева и двумя справа, подтверждённый только после закрытия правых свечей. Среди подтверждённых цен последних 120 свечей выбирается ближайшая ниже и выше закрытия. При смене стороны ранее подтверждённая цена может менять роль. Если подходящего уровня нет, отображается «—».
- Тренд: `close > EMA20 > EMA50` — восходящий; `close < EMA20 < EMA50` — нисходящий; иначе смешанный.
- Расчётный сценарий: от цены закрытия SL на расстоянии 1,5 ATR и TP на 3 ATR. Объём в калькуляторе — риск в USD / расстояние до SL, округлённый вниз до 0,01 унции. Он не учитывает расходы, маржу и спецификацию лота брокера. В историческом исследовании расходы учитываются отдельно.

| Часть оценки | Баллы |
|---|---:|
| Цена и EMA20/50 в одном направлении | 25 |
| Цена по соответствующую сторону EMA200 | 15 |
| RSI 55–70 для роста или 30–45 для снижения | 15 |
| MACD и гистограмма в направлении тренда | 15 |
| Активность не ниже 1,5 среднего | 10 |
| ATR в диапазоне 0,75–2 медиан | 10 |
| Пробой по направлению либо близкий соответствующий уровень | 10 |

В интерфейсе внутренний статус WATCH показан как «Условия совпали · проверьте вручную». Он появляется от 70 баллов при определённом направлении и выделяется янтарным цветом. **75/100 не означает 75% вероятности успеха.** При устаревших данных показывается «Данные устарели», до разогрева — «Недостаточно свечей», ниже порога — «Порог не достигнут». Надпись «MT5 · данные поступают» относится только к свежести источника. Индикаторные события сохраняются в локальной ленте; их отправка в Telegram в живом режиме выключена. Telegram-планы FVG/SBR/RBS — отдельные сообщения.

## Telegram и сохранение событий

Во вкладке «Уведомления» вводятся токен бота, числовой chat_id своего чата и флаг включения. Перед настройкой нужно отправить боту `/start`. Кнопка теста отправляет явно обозначенное тестовое сообщение.

Секреты хранятся в `runtime/telegram-settings.json` через Windows DPAPI, привязанный к текущему пользователю Windows. API не возвращает токен. Файлы `runtime/` исключены из Git.

События и статусы доставки хранятся в `runtime/alerts.sqlite3`. Повтор типа события на одном периоде ограничен 30 минутами; сами подавленные события сохраняются. При возрасте события или котировки больше 90 секунд новое уведомление не создаётся. Очередь отправки истекает через 180 секунд. HTTP 429 обрабатывается с ожиданием, указанным Telegram. При неподтверждённой сетевой доставке слепого повтора нет, чтобы не дублировать сообщение; ошибка остаётся в журнале.

После перезапуска сохранённые идентификаторы защищают от повторной отправки. При закрытии программы новые события не отслеживаются; историческое восстановление после запуска не выдаётся за живой сигнал.

**Telegram подключён 27 сентября 2026 года:** создан отдельный бот `@XauRadarLocal_20260927_bot`, пользователь сохранил токен в локальной форме, chat_id личного диалога определён по проверочной команде. Доставка включена; тестовое сообщение подтверждено API и проверено в интерфейсе Telegram. Токен в документацию не записывается.

## Файлы и воспроизведение

- `radar_config.json` — определения нового обзора; `config.json` — отдельный старый FVG-сценарий.
- `app/indicators.py`, `app/market_radar.py` — расчёты и исторический обзор.
- `app/live_market.py`, `app/mt5_bridge.py` — чтение MT5 и события.
- `app/notifications.py` — защищённые настройки и очередь Telegram.
- `app/technical_research.py` — воспроизводимая историческая проверка WATCH.
- `web/market.js` — новый экран.
- `results/technical_history.json`, `results/technical_validation.json` — расчёты и условные опыты.
- `results/market-ui-check.json`, `results/ui-check.json` — браузерные проверки.

Из корня проекта:

```powershell
python -m pip install --user -r requirements-mt5.txt
python -X utf8 -m app.market_radar
python -X utf8 -m app.technical_research
python -X utf8 -m unittest discover -s tests -v
```

Обычный запуск — `start.bat`, затем http://127.0.0.1:8767 . Запускаются сервер и MT5-мост. Компьютер и терминал должны оставаться включёнными. При временной ошибке чтения мост пробует восстановить соединение; старый снимок остаётся явно устаревшим. После изменения Python-кода нужен перезапуск соответствующих процессов.

Документация интеграций: [MT5: закрытые свечи](https://www.mql5.com/en/docs/python_metatrader5/mt5copyratesfrompos_py), [MT5: последняя котировка](https://www.mql5.com/en/docs/python_metatrader5/mt5symbolinfotick_py), [Telegram sendMessage](https://core.telegram.org/bots/api#sendmessage).
