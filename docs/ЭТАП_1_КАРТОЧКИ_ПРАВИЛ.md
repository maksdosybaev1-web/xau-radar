## Карточки сценариев

Поля «не задано» означают именно отсутствие надёжного авторского условия. Они не являются разрешением произвольно подставить параметр из кода. Схемы карточек нужны для следующего этапа реализации, но этот документ **не включает** новый детектор.

### 1. Свечная зона, путь H1 → M15 → M5

- **Контекст:** выбрать H1-зону; общий старший контекст и ликвидность учитываются в примерах. Точный автоматический фильтр неизвестен.
- **Зона:** найти подходящую M15-зону внутри H1, затем уточнить её на M5. Тип свечной зоны может быть imbalance, order block или иной buy/sell-зоной, а не только FVG.
- **Подтверждение:** по варианту примера — реакция/закрытие младшей свечи; одного универсального условия нет.
- **Вход:** касание/лимит либо после закрытия; режим должен выбираться до наблюдения исхода.
- **Отмена:** автор не даёт общего времени жизни, числа касаний и точной цены нарушения зоны.
- **Стоп:** за выбранной зоной или экстремумом; конкретный буфер неизвестен.
- **Цель:** ближайшая подходящая ликвидность или противоположная зона; единый RR неизвестен.
- **Источник:** V3 01:55–08:50; 10:43–13:11; V1 18:26–19:25. **Наш FVG-код** реализует лишь одну численную трактовку.

### 2. Свечная зона, путь M15 → M5 → M1

- **Контекст:** локальный вариант для более короткого горизонта; V3 02:54–03:22 смягчает роль большого контекста, но не отменяет анализ логики рынка/ликвидности.
- **Зона:** M15 → внутренняя M5 → точка M1. Вложенность свечных зон поддержана; её точная геометрия не задана.
- **Подтверждение и вход:** показаны уточнение и варианты касания/закрытия; обязательная форма M1-свечи не установлена.
- **Отмена, стоп, цель:** отдельной полной формулы для этого пути нет.
- **Источник:** V3 01:55–03:22; 10:43–16:37. **Статус:** как отдельный сценарий в проекте не реализован.

### 3. Classic A SELL и Classic V BUY

- **Контекст:** в базовом уроке продажа/покупка рассматривается по направлению структуры; локальные исключения не формализованы.
- **Зона:** верхний разворот линейного графика для A; нижний для V.
- **Подтверждение:** сам по себе рисунок формы ещё не содержит однозначного свечного триггера.
- **Вход:** рассмотреть сделку при возврате к зоне; касание против закрытия не закреплено отдельно за Classic.
- **Отмена:** число повторов, срок и критерий полного пробоя не даны.
- **Стоп:** за зоной/экстремумом — общий принцип из примеров; число неизвестно.
- **Цель:** по ближайшей подходящей зоне/ликвидности; численной формулы нет.
- **Источник:** V2 03:42–04:39, 09:30–12:38. **Статус:** самостоятельного детектора нет.

### 4. RBS BUY

- **Контекст:** прежнее сопротивление и последующий пробой; общий тренд в уроке желателен, но обязательность H1-фильтра для RBS не задана.
- **Зона:** бывшее сопротивление, получившее роль поддержки.
- **Подтверждение:** возврат к уровню; точный критерий пробоя и свечи реакции неизвестен.
- **Вход:** рассмотрение buy на возврате, способ исполнения не закреплён.
- **Отмена:** срок, допустимые повторные касания и нарушение уровня неизвестны.
- **Стоп/цель:** отдельной универсальной формулы для RBS нет.
- **Источник:** V2 04:39–05:37 и [кадр](evidence/step2/definition_0315.jpg). **Наш детектор:** закрытая M5, полоса 0,1 ATR, первый возврат, H1-фильтр и цель M15 — исследовательские допущения из [спецификации](SNR_RBS_SPEC.md).

### 5. SBR SELL

- **Контекст:** прежняя поддержка и последующий пробой вниз; общий тренд в уроке желателен, но обязательность H1-фильтра для SBR не задана.
- **Зона:** бывшая поддержка, получившая роль сопротивления.
- **Подтверждение:** возврат снизу; точное закрытие и ширина уровня неизвестны.
- **Вход:** рассмотрение sell на возврате; в V3 модель сочетается со свечными зонами.
- **Отмена:** срок и повторные касания не заданы однозначно.
- **Стоп/цель:** на показанных сделках привязаны к зоне/ликвидности, но общей формулы нет.
- **Источник:** V2 05:37–06:08; V3 19:15–24:45, [кадр](evidence/step2/example_1380.jpg). **Наш детектор:** первый возврат, закрытая M5, ATR-буфер, цель M15 и расходы — отдельные допущения из [спецификации](SNR_SBR_SPEC.md).

### 6. QML BUY и QML SELL

- **Контекст:** на линейном графике формируется уровень после смены направленного движения; жёсткая привязка к H1 и старшей свечной зоне не подтверждена.
- **Зона:** уровень после пробоя и обратного пробоя; для buy/sell последовательность зеркальная.
- **Подтверждение:** нужен возврат к полученному уровню, но точная последовательность экстремумов и допустимое число касаний остаются неясными.
- **Вход:** buy/sell на соответствующем возврате; касание или закрытие не закреплены универсально.
- **Отмена:** нельзя достоверно установить по этим материалам, запрещён ли второй контакт или только второй вход.
- **Стоп/цель:** общей авторской формулы нет.
- **Источник:** V2 06:08–08:30, 13:08–13:34, 17:50–18:18; V3 14:39–16:37. **Статус:** самостоятельного детектора нет; неоднозначность повторов блокирует точное утверждение «по правилам автора».

### 7. OCL BUY и OCL SELL

- **Контекст:** только вместе с уже определённой buy/sell-зоной соответствующей стороны.
- **Зона:** участок между соседними свечами, показанный на [кадре OCL](frames/v2/0018.jpg); точные границы тел/теней не определены.
- **Подтверждение:** не дан самостоятельный полный триггер OCL.
- **Вход:** вспомогательное уточнение уже выбранной зоны, не автоматический вход по любой паре свечей.
- **Отмена, стоп, цель:** отдельных однозначных правил нет; должны наследоваться от основного сценария только после явного выбора такого сценария.
- **Источник:** V2 08:30–08:58; 18:19–19:17. **Статус:** отдельного детектора нет.

## Что мешает назвать методику полностью формализованной

1. **Контекст:** V2 запрещает боковик в базовом объяснении, V3 допускает локальный сценарий с менее жёстким большим контекстом. Нужны два явно названных режима либо разъяснение автора.
2. **Вложенность:** для свечных зон правило выражено сильно; для самостоятельной SNR-зоны допускается исключение. Точная граница случаев не установлена.
3. **QML:** «одна отработка» и пример двух реакций нельзя свести в точное правило без определения касания и повторного входа.
4. **Цена зоны:** нет численной ширины, допуска на пробой/касание, срока жизни и общего правила выбора из нескольких уровней.
5. **Исполнение:** вход лимитом и вход после закрытия — разные проверяемые стратегии. Однозначного выбора между ними нет.
6. **Риск:** нет общего расстояния стопа, цели, размера позиции и правила частичного выхода; показанные числа не универсальны.
7. **Ликвидность:** по графику можно фиксировать гипотезу автора о стопах, но нельзя утверждать наблюдение фактических стоп-заявок.

## Результат этапа 1

Собран перечень правил и карточки всех названных моделей/двух связок. Определено, где источник поддерживает принцип, а где проект добавил числа и ограничения. Материалы достаточны, чтобы **раздельно исследовать выбранные трактовки**, но недостаточны, чтобы объявить полный автоматический радар точной копией автора. Следующий этап не выполнялся.
