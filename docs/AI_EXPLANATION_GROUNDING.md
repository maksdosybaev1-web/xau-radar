# Проверка ИИ-пояснений в радаре — 27 сентября 2026

Проверены два сохранённых ответа `qwen2.5:7b` для подтверждённых исторических FVG-событий **8** и **19**. У события 8 модель указала вложенность M15-зоны, касание закрытой M5 и стоп, но опустила направление H1. У события 19 указала направление H1, касание M5 и стоп, но опустила явную вложенность M15-зоны в H1. Эти условия есть в исходных записях радара. Оба ответа остаются только формулировками модели; они не меняли сигналы.

Теперь блок «Объяснить локальной ИИ-моделью» показывает две ясно подписанные части: **условия по записи радара** (направление, H1, вложенная M15-зона, закрытая M5, стоп и статус учебной симуляции) и **формулировку модели**, которая может быть неполной. Для прежних кешированных ответов проверенные условия собираются из сохранённого события при выдаче API; повторный вызов модели не требуется. Кнопка по-прежнему доступна только для подтверждённых событий.

Через действующий `/api/explain` оба события повторно получены: в `verified_facts` присутствуют пропущенные моделью условия, а `text` остаётся исходным ответом `qwen2.5:7b`. Синтаксис JavaScript проверен `node --check web/app.js`; общий набор — **130 тестов, OK**. Это проверяет показ известных условий пользователю, но не доказывает верность торговой методики, полноту ИИ-текста или пользу ИИ-фильтра.

На момент этой проверки мост MT5 перешёл в `retrying`: терминал отвечает на сведения о демосчёте и XAUUSD, но запросы M1 и тиков возвращают `Terminal: Call failed`. Подтверждено **0 открытых позиций и 0 заявок**. Повторное чтение вне песочницы и перезапуск терминала с мостом не восстановили историю. Computer-use нашёл приложение, но доступного окна MT5 нет; попытка открыть его также не дала целевого окна. Поэтому новых forward-результатов пока нет; мост сохраняет состояние переподключения вместо ложного сигнала.
