# Исторические исходы двух режимов входа: версия исследования 1

## Что именно сравнивается

Исходные события — только первый возврат к внутренней M1-зоне из [связки M15 → M5 → M1](NESTED_M15_M5_M1_SPEC.md) и два раздельных [кандидата входа](ENTRY_MODES_SPEC.md). Правила кандидатов и набор из 1 575 первых возвратов зафиксированы до расчёта исходов. Никакие сделки не отправляются брокеру. Это исследование **не воспроизводит авторские сделки**: в видео нет единой численной формулы стопа, цели, размера и исполнения.

Входы оцениваются как **независимые условные опыты**. Несколько цепочек могут использовать одну зону и пересекаться во времени; их P/L нельзя складывать в кривую общего счёта или называть просадкой портфеля. Закрытые исходы не являются доказательством доходности на новых данных.

## Заранее заданные допущения проекта

| Параметр | Правило |
|---|---|
| Стоп | Для BUY: нижняя граница внутренней M1-зоны минус 0,1 ATR(14) M1. Для SELL: верхняя граница плюс 0,1 ATR(14). ATR рассчитывается только по полностью закрытым последовательным M1 к моменту знания цепочки и затем фиксируется. |
| Цель | 2R от условной цены входа по расстоянию до стопа **до расходов**. Это исследовательский ориентир, не авторская цель по ликвидности. |
| Вход `touch_limit` | Только `resting_limit_crossing`; условная цена — граница зоны. `limit_crossed_at_open` исключается из сравнения строгой ожидавшей лимитной заявки. Даже при пересечении исполнение очереди заявок неизвестно. |
| Вход `after_close` | Только `next_open_candidate`; условная цена ask/bid следующей M1 с неблагоприятным проскальзыванием 0,05 USD/унцию. |
| Расходы и риск | Комиссия 0,04 USD/унцию за сторону; неблагоприятное проскальзывание выхода 0,05 USD/унцию. Не тариф брокера. Условный риск опыта 25 USD; объём `25/(расстояние до стопа + проскальзывание выхода + 2 комиссии)`. |
| Защитные фильтры | Положительное расстояние до стопа; спред на открытии минуты входа не более 1 USD и не более 20% расстояния до стопа. Для лимита спред в начале минуты — лишь приближение спреда при касании. |
| Выход | По bid для BUY и ask для SELL. При одновременном достижении стопа и цели в одной последующей M1 консервативный приоритет стопа. Неблагоприятный гэп за стоп — по худшей цене открытия. Цель — по указанной цене без благоприятного улучшения. Если границы не достигнуты, выход по закрытию через 60 минут. Разрыв M1 или конец архива раньше выхода — неполный исход. |
| Минута входа лимитом | Если её OHLC также пересекает стоп либо цель, состояние `entry_bar_path_unknown`: невозможно определить, было ли касание границы до или после лимита. Такой опыт исключается из статистики закрытых исходов. Иначе оценка начинается со следующей M1. Для входа по следующему открытию границы проверяются с этой же M1. |

Статусы отказов, неполных исходов и неопределённой минуты сохраняются наряду с закрытыми. Сравнение включает два среза: все закрытые опыты по каждому режиму и **попарно закрытые** опыты на одной и той же цепочке. Первый срез имеет разные наборы ситуаций из-за разных правил подтверждения; разницу его средних нельзя приписывать только способу исполнения. Даже попарный срез не является причинной оценкой без реальных тиков, брокерских расходов и новых данных.

Минутные OHLC не восстанавливают последовательность тиков. В [документации тестера MetaTrader 5](https://www.mql5.com/en/docs/runtime/testing) режим «1 minute OHLC» отдельно отличён от тестирования на реальных тиках именно по детализации движения внутри бара. Наш расчёт не использует реальную тиковую историю брокера.

## Воспроизведение

`python -X utf8 -m app.entry_modes_outcomes_research` создаёт `results/entry_modes_outcomes_run.json`, `results/entry_modes_outcomes_events.jsonl`. Скрипт проверяет SHA256 CSV и обеих входных спецификаций/журналов. Изменение любого условия требует новой версии исследования и отдельного отчёта.
