# Проверка ИИ-разбора журнала — 27 сентября 2026

Проверен локальный `qwen2.5:7b` на [историческом журнале двух режимов](../results/entry_modes_outcomes_run.json). Скрипт [`app/ai_journal.py`](../app/ai_journal.py) сам считает состояния и причины по всем **3 150** условным опытам, сверяет суммы с сохранённой сводкой и передаёт модели только компактные факты. Он не меняет сигналы, заявки или Telegram.

Первая попытка Ollama ошибочно представила `limit_crossed_at_open` главной причиной отсева лимитных кандидатов. В журнале таких случаев **46**, а главная причина — `spread_guard` (**1 528**). Этот [черновик отклонён](../results/ai_journal_review_attempt1_rejected.md). После уточнения входных данных вторая попытка не вернула ожидаемые ключи главных причин; проверка отклонила ответ до сохранения итогового отчёта. Свободный текст модели не был принят как доказанный анализ.

[Итоговая сводка](../results/ai_journal_review.md) построена напрямую из журнала без текста Ollama. В ней указаны главные причины по каждому режиму, отсутствие попарно закрытых опытов и нулевой текущий forward-журнал. Команда воспроизведения без нового вызова модели: `python -X utf8 -m app.ai_journal --no-model`. В обычном режиме скрипт проверяет ключи главных причин; при ошибке возвращается к проверенной числовой сводке. Даже если ключи верны, свободный текст модели остаётся черновиком для отдельной сверки.

Прошли **118 тестов**, включая контроль расхождения итогов с опытом и отклонение неверной главной причины. Это проверка достоверности разбора журнала, **не оценка пользы ИИ для отбора сделок**. Для такого сравнения пока нет заранее зафиксированных ИИ-решений по новым сигналам и достаточных независимых исходов; на текущей истории попарно завершённых опытов двух режимов **0**. Радар продолжает работать по исходным правилам.
